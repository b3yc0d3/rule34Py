class Tag(count: int, type: TagType, tag: str)

A Rule34 Tag object.

Note

This object can behave as a normal string, for backwards compatibility.

Parameters:

  • count (int) – Usage count of the Tag.

  • type (TagType) – Type of the Tag.

  • tag (str) – String value of the Tag.
